Quick guide

  1. Add assets and save them locally in this browser.
  2. Use the QR button on an asset to display/download its QR. The QR contains the asset ID and is generated offline.
  3. Scan a QR from a secure browser page on a device with a camera, or type the ID manually.
  4. Use Edit to update details, or Check to record maintenance status and notes.
  5. Export a JSON backup regularly. Import a backup to restore records on this device.
  6. Gemini is optional and needs internet plus your own API key; records remain local unless you explicitly ask Gemini a question.
